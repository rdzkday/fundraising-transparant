# fundraising-transparant
fundraising yang transparan hingga ke aliran dananya.

## Database (Supabase)

Skema ada di `supabase/migrations/`. Setiap perubahan database ditulis sebagai file migrasi baru di folder itu.

Hubungkan ke Supabase: Dashboard → Project Settings → Integrations → GitHub → pilih repo ini, folder `supabase`. Migrasi akan dijalankan otomatis saat branch `main` berubah.
